What this demo does not do yet

  • No per-line heatmap: each line shows its score as a number, not as a coloured strip (planned for the v0.1 demo).
  • Devanagari only: Tamil and Bengali come later, and text in any other script is treated as plain text, so a Latin line scores clean.
  • Structural checks only: it cannot see visually plausible OCR confusions (ब for व), a well-formed but wrong word, or legacy-font text that was read back as Latin letters.
  • The rule weights come from how badly each defect breaks rendering or reading; they are not calibrated on real documents, and the benchmark behind them uses synthetic text only.
  • No file drag-and-drop: paste text instead. Input is limited to 1 MiB of UTF-8.
  • No service worker: offline after the first load is best effort (Chrome's HTTP cache), not guaranteed.
  • Nothing is published yet: no npm package or Python wheel.

Document score

—

Each flagged cluster costs the largest weight among its issues; the score is 1 − penalty × 1000 ÷ clusters, in parts per million, shown with four decimals (truncated, never rounded) by integer arithmetic. 1.0000 is clean; empty text scores 1.0000.

Lines

One row per line (LF, CRLF or a bare CR ends a line). The score is the same formula applied to that line alone. Invisible or private-use code points are shown as ⟨U+XXXX⟩.
